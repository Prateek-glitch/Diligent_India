# Build Your Own Jarvis

This repository contains the source code for the "Build Your Own Jarvis" project. The project implements a personal AI assistant powered by a self-hosted large language model (LLM) like LLaMA, integrated with a vector database (e.g., Pinecone or FAISS) and a chatbot UI.

## Key Components
- **Self-hosted Large Language Model (LLM)**: Processes user queries and responds contextually.
- **Vector Database**: Stores and retrieves enterprise knowledge efficiently.
- **Conversational Chatbot UI**: Provides an interface for users to interact with the assistant.

## Features
1. Natural Language Understanding using an LLM.
2. Knowledge management and retrieval with a vector database.
3. Interactive and visually appealing chatbot UI.

This project is structured for scalability and maintainability. Check out the directory layout for more details.
